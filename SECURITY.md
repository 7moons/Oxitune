# Security

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately through
[GitHub security advisories](https://github.com/7moons/Oxitune/security/advisories/new)
on this repository, with the steps to reproduce it and what an attacker could gain.

## What to expect

Reports are read by the maintainers. There is no bounty. Fixes ship as a normal release; the
changelog says what was fixed once users had time to update.

## Design

How Oxitune limits what the YouTube Music page can reach, how Listen Together is encrypted and
how updates are signed is described under *Security* in the [README](README.md#security).
